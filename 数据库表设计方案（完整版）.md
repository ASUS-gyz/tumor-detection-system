# 数据库表设计方案（完整版）

> **基于**：业务功能文档（学生开发版）+ 后端接口文档 V1.0（47 接口）
>
> **版本**：V2.1 | **日期**：2026-07-27 | **表数**：8 张业务表 + 2 张 Laravel 辅助表

------

## 一、总览

### 1.1 表清单

| 表名                     | 说明           | 核心职责                                             |
| :----------------------- | :------------- | :--------------------------------------------------- |
| `users`                  | 用户表         | 患者/医生/管理员三合一，role 区分                    |
| `appointments`           | 预约表         | 患者预约 → 医生叫号 → 接诊 → 完成                    |
| `medical_records`        | 病历表         | 一个预约对应一份肿瘤科病历                           |
| `prescriptions`          | 处方表         | 一次就诊可开多张处方                                 |
| `prescription_items`     | 处方明细表     | 处方中的药品清单                                     |
| `ai_diagnoses`           | AI 诊断报告表  | 文字诊断（患者）+ 图文诊断（医生）                   |
| `drugs`                  | 药品表         | 药品目录与库存管理                                   |
| `stock_movements`        | 库存变动记录表 | 入库/出库全程追溯                                    |
| `password_reset_tokens`  | 密码重置令牌表 | Laravel 内置，`php artisan migrate` 自动生成         |
| `personal_access_tokens` | API 令牌表     | Laravel Sanctum 认证，`php artisan migrate` 自动生成 |

> 注：后两张辅助表由 Laravel 框架命令自动创建，无需手动编写迁移，本文档仅列出业务表设计。

### 1.2 表关系图

```
users (1) ──< appointments (N: patient)
users (1) ──< appointments (N: doctor)
users (1) ──< medical_records (N)
users (1) ──< prescriptions (N)
users (1) ──< ai_diagnoses (N)
users (1) ──< stock_movements (N: operator)

appointments (1) ──< medical_records (1:1)
appointments (1) ──< prescriptions (N)
appointments (1) ──< ai_diagnoses (N)

prescriptions (1) ──< prescription_items (N)

drugs (1) ──< prescription_items (N)
drugs (1) ──< stock_movements (N)
```

### 1.3 与原始设计 V2.0 的变更

| 表                 | 新增字段                                                     | 说明                                     |

## 二、详细表设计

### 2.1 用户表 `users`

所有角色共用此表，通过 `role` 区分。患者自助注册，医生/管理员由后台创建。

| 字段名              | 数据类型                         | 必填 | 默认值            | 说明                            |
| :------------------ | :------------------------------- | :--- | :---------------- | :------------------------------ |
| `id`                | BIGINT UNSIGNED                  | ✅    | AUTO_INCREMENT    | 主键                            |
| `name`              | VARCHAR(50)                      | ✅    | —                 | 姓名，2-50 字符，支持中文       |
| `email`             | VARCHAR(255)                     | ✅    | —                 | 邮箱，唯一                      |
| `email_verified_at` | TIMESTAMP                        | 否   | NULL              | 邮箱验证时间                    |
| `password`          | VARCHAR(255)                     | ✅    | —                 | bcrypt 加密存储                 |
| `remember_token`    | VARCHAR(100)                     | 否   | NULL              | 记住登录令牌                    |
| `role`              | ENUM('patient','doctor','admin') | ✅    | —                 | 角色                            |
| `gender`            | ENUM('male','female','other')    | 否   | NULL              | 性别                            |
| `birth_date`        | DATE                             | 否   | NULL              | 出生日期                        |
| `phone`             | VARCHAR(20)                      | 否   | NULL              | 手机号，11 位                   |
| `avatar_url`        | VARCHAR(255)                     | 否   | NULL              | 头像访问地址                    |
| `status`            | ENUM('active','disabled')        | ✅    | 'active'          | 账号状态                        |
| `title`             | VARCHAR(50)                      | 否   | NULL              | 职称（仅 doctor），如"主任医师" |
| `specialty`         | VARCHAR(255)                     | 否   | NULL              | 专长（仅 doctor）               |
| `department`        | VARCHAR(100)                     | 否   | NULL              | 科室（仅 doctor）               |
| `introduction`      | TEXT                             | 否   | NULL              | 个人简介（仅 doctor）           |
| `experience_years`  | INT UNSIGNED                     | 否   | NULL              | 从业年限（仅 doctor）           |
| `created_at`        | TIMESTAMP                        | ✅    | CURRENT_TIMESTAMP | 创建时间                        |
| `updated_at`        | TIMESTAMP                        | ✅    | CURRENT_TIMESTAMP | 更新时间                        |

**索引**：`email` UNIQUE, `role` INDEX, `status` INDEX

```
Schema::create('users', function (Blueprint $table) {
    $table->id()->comment('主键ID');
    $table->string('name', 50)->comment('姓名');
    $table->string('email', 255)->unique()->comment('邮箱');
    $table->timestamp('email_verified_at')->nullable()->comment('邮箱验证时间');
    $table->string('password', 255)->comment('密码');
    $table->rememberToken()->comment('记住登录令牌');
    $table->enum('role', ['patient', 'doctor', 'admin'])->comment('角色');
    $table->enum('gender', ['male', 'female', 'other'])->nullable()->comment('性别');
    $table->date('birth_date')->nullable()->comment('出生日期');
    $table->string('phone', 20)->nullable()->comment('手机号');
    $table->string('avatar_url', 255)->nullable()->comment('头像地址');
    $table->enum('status', ['active', 'disabled'])->default('active')->comment('账号状态');
    // 医生专属字段
    $table->string('title', 50)->nullable()->comment('职称');
    $table->string('specialty', 255)->nullable()->comment('专长');
    $table->string('department', 100)->nullable()->comment('科室');
    $table->text('introduction')->nullable()->comment('个人简介');
    $table->unsignedInteger('experience_years')->nullable()->comment('从业年限');
    $table->timestamps();

    $table->index('role');
    $table->index('status');
});
```

### 2.2 预约表 `appointments`

患者创建预约，医生管理接诊。对应患者端"预约管理"和医生端"接诊管理"。

| 字段名             | 数据类型                                                     | 必填 | 默认值            | 说明                                                         |
| :----------------- | :----------------------------------------------------------- | :--- | :---------------- | :----------------------------------------------------------- |
| `id`               | BIGINT UNSIGNED                                              | ✅    | AUTO_INCREMENT    | 主键                                                         |
| `patient_id`       | BIGINT UNSIGNED                                              | ✅    | —                 | 患者 ID，FK → `users.id`                                     |
| `doctor_id`        | BIGINT UNSIGNED                                              | ✅    | —                 | 医生 ID，FK → `users.id`                                     |
| `appointment_date` | DATE                                                         | ✅    | —                 | 预约日期，不能早于当天                                       |
| `appointment_time` | VARCHAR(5)                                                   | ✅    | —                 | 时段 HH:mm，可选值：08:30/09:15/10:00/10:45/13:30/14:15/15:00/15:45 |
| `status`           | ENUM('pending','called','in_progress','completed','cancelled') | ✅    | 'pending'         | 预约状态                                                     |
| `called_at`        | TIMESTAMP                                                    | 否   | NULL              | 叫号时间                                                     |
| `started_at`       | TIMESTAMP                                                    | 否   | NULL              | 开始接诊时间                                                 |
| `completed_at`     | TIMESTAMP                                                    | 否   | NULL              | 结束接诊时间                                                 |
| `cancelled_at`     | TIMESTAMP                                                    | 否   | NULL              | 取消时间                                                     |
| `cancel_reason`    | VARCHAR(255)                                                 | 否   | NULL              | 取消原因                                                     |
| `created_at`       | TIMESTAMP                                                    | ✅    | CURRENT_TIMESTAMP | 创建时间                                                     |
| `updated_at`       | TIMESTAMP                                                    | ✅    | CURRENT_TIMESTAMP | 更新时间                                                     |

**状态流转**：`pending → called → in_progress → completed`；`pending → cancelled`

**业务约束**：

- 患者同时只能有 1 个进行中预约（应用层校验 + 数据库部分唯一索引）
- 仅 `pending` 状态可取消
- 预约日期不能早于当天

**索引**：`(patient_id, status)` INDEX, `(doctor_id, appointment_date)` INDEX, `appointment_date` INDEX, `status` INDEX

```
Schema::create('appointments', function (Blueprint $table) {
    $table->id()->comment('主键ID');
    $table->unsignedBigInteger('patient_id')->comment('患者ID');
    $table->unsignedBigInteger('doctor_id')->comment('医生ID');
    $table->date('appointment_date')->comment('预约日期');
    $table->string('appointment_time', 5)->comment('预约时段 HH:mm');
    $table->enum('status', ['pending', 'called', 'in_progress', 'completed', 'cancelled'])
          ->default('pending')->comment('预约状态');
    // 状态流转时间戳
    $table->timestamp('called_at')->nullable()->comment('叫号时间');
    $table->timestamp('started_at')->nullable()->comment('开始接诊时间');
    $table->timestamp('completed_at')->nullable()->comment('结束接诊时间');
    $table->timestamp('cancelled_at')->nullable()->comment('取消时间');
    $table->string('cancel_reason', 255)->nullable()->comment('取消原因');
    $table->timestamps();

    $table->foreign('patient_id')->references('id')->on('users');
    $table->foreign('doctor_id')->references('id')->on('users');
    $table->index(['patient_id', 'status']);
    $table->index(['doctor_id', 'appointment_date']);
    $table->index('appointment_date');
    $table->index('status');
});
```

### 2.3 病历表 `medical_records`

一个预约对应最多 1 份病历，由医生在接诊过程中创建并填写。

| 字段名                  | 数据类型        | 必填 | 默认值            | 说明                                        |
| :---------------------- | :-------------- | :--- | :---------------- | :------------------------------------------ |
| `id`                    | BIGINT UNSIGNED | ✅    | AUTO_INCREMENT    | 主键                                        |
| `appointment_id`        | BIGINT UNSIGNED | ✅    | —                 | 关联预约 ID，FK → `appointments.id`，UNIQUE |
| `patient_id`            | BIGINT UNSIGNED | ✅    | —                 | 患者 ID，FK → `users.id`                    |
| `doctor_id`             | BIGINT UNSIGNED | ✅    | —                 | 医生 ID，FK → `users.id`                    |
| `symptoms`              | TEXT            | ✅    | —                 | 症状描述                                    |
| `imaging_findings`      | TEXT            | 否   | NULL              | 影像检查情况                                |
| `preliminary_diagnosis` | TEXT            | ✅    | —                 | 初步诊断                                    |
| `treatment_plan`        | TEXT            | ✅    | —                 | 诊疗医嘱                                    |
| `remark`                | TEXT            | 否   | NULL              | 补充说明/复诊建议                           |
| `created_at`            | TIMESTAMP       | ✅    | CURRENT_TIMESTAMP | 创建时间                                    |
| `updated_at`            | TIMESTAMP       | ✅    | CURRENT_TIMESTAMP | 更新时间                                    |

**业务约束**：

- 创建需预约状态为 `in_progress`
- 同一预约仅可创建 1 份病历（`appointment_id` UNIQUE 保证）

**索引**：`appointment_id` UNIQUE, `patient_id` INDEX, `created_at` INDEX

```
Schema::create('medical_records', function (Blueprint $table) {
    $table->id()->comment('主键ID');
    $table->unsignedBigInteger('appointment_id')->unique()->comment('关联预约ID');
    $table->unsignedBigInteger('patient_id')->comment('患者ID');
    $table->unsignedBigInteger('doctor_id')->comment('医生ID');
    $table->text('symptoms')->comment('症状描述');
    $table->text('imaging_findings')->nullable()->comment('影像检查情况');
    $table->text('preliminary_diagnosis')->comment('初步诊断');
    $table->text('treatment_plan')->comment('诊疗医嘱');
    $table->text('remark')->nullable()->comment('补充说明/复诊建议');
    $table->timestamps();

    $table->foreign('appointment_id')->references('id')->on('appointments');
    $table->foreign('patient_id')->references('id')->on('users');
    $table->foreign('doctor_id')->references('id')->on('users');
    $table->index('patient_id');
    $table->index('created_at');
});
```

### 2.4 处方表 `prescriptions`

同一预约可开具多张处方。开具时校验库存（不扣减），患者确认取药时扣减。

| 字段名           | 数据类型                    | 必填 | 默认值            | 说明                                |
| :--------------- | :-------------------------- | :--- | :---------------- | :---------------------------------- |
| `id`             | BIGINT UNSIGNED             | ✅    | AUTO_INCREMENT    | 主键                                |
| `appointment_id` | BIGINT UNSIGNED             | ✅    | —                 | 关联预约 ID，FK → `appointments.id` |
| `patient_id`     | BIGINT UNSIGNED             | ✅    | —                 | 患者 ID，FK → `users.id`            |
| `doctor_id`      | BIGINT UNSIGNED             | ✅    | —                 | 开具医生 ID，FK → `users.id`        |
| `status`         | ENUM('pending','dispensed') | ✅    | 'pending'         | pending-待取药，dispensed-已取药    |
| `total_amount`   | DECIMAL(10,2)               | 否   | NULL              | 处方总金额（处方明细金额之和）      |
| `dispensed_at`   | TIMESTAMP                   | 否   | NULL              | 取药时间                            |
| `notes`          | TEXT                        | 否   | NULL              | 处方整体备注/医嘱                   |
| `created_at`     | TIMESTAMP                   | ✅    | CURRENT_TIMESTAMP | 开具时间                            |
| `updated_at`     | TIMESTAMP                   | ✅    | CURRENT_TIMESTAMP | 更新时间                            |

**业务约束**：

- 开具时校验每项药品库存（不足则整体拒绝），不扣减库存
- 患者确认取药时扣减库存并生成库存变动记录
- `total_amount` 在创建处方时从明细汇总计算

**索引**：`status` INDEX, `patient_id` INDEX

```
Schema::create('prescriptions', function (Blueprint $table) {
    $table->id()->comment('主键ID');
    $table->unsignedBigInteger('appointment_id')->comment('关联预约ID');
    $table->unsignedBigInteger('patient_id')->comment('患者ID');
    $table->unsignedBigInteger('doctor_id')->comment('开具医生ID');
    $table->enum('status', ['pending', 'dispensed'])->default('pending')->comment('处方状态');
    $table->decimal('total_amount', 10, 2)->nullable()->comment('处方总金额');
    $table->timestamp('dispensed_at')->nullable()->comment('取药时间');
    $table->text('notes')->nullable()->comment('处方备注/医嘱');
    $table->timestamps();

    $table->foreign('appointment_id')->references('id')->on('appointments');
    $table->foreign('patient_id')->references('id')->on('users');
    $table->foreign('doctor_id')->references('id')->on('users');
    $table->index('status');
    $table->index('patient_id');
});
```

### 2.5 处方明细表 `prescription_items`

处方中的药品明细，与 `prescriptions` 为一对多关系。

| 字段名            | 数据类型        | 必填 | 默认值            | 说明                                      |
| :---------------- | :-------------- | :--- | :---------------- | :---------------------------------------- |
| `id`              | BIGINT UNSIGNED | ✅    | AUTO_INCREMENT    | 主键                                      |
| `prescription_id` | BIGINT UNSIGNED | ✅    | —                 | 处方 ID，FK → `prescriptions.id`，CASCADE |
| `drug_id`         | BIGINT UNSIGNED | ✅    | —                 | 药品 ID，FK → `drugs.id`                  |
| `quantity`        | INT UNSIGNED    | ✅    | —                 | 数量，>0                                  |
| `unit_price`      | DECIMAL(10,2)   | ✅    | —                 | 开具时药品单价（从 `drugs.price` 快照）   |
| `dosage`          | VARCHAR(255)    | ✅    | —                 | 用量说明，如"每日3次，每次1片"            |
| `instructions`    | TEXT            | 否   | NULL              | 用药说明，如"饭后服用，忌辛辣刺激食物"    |
| `created_at`      | TIMESTAMP       | ✅    | CURRENT_TIMESTAMP | 创建时间                                  |
| `updated_at`      | TIMESTAMP       | ✅    | CURRENT_TIMESTAMP | 更新时间                                  |

**设计要点**：`unit_price` 是 `drugs.price` 的快照。药品价格可能调价，但历史处方应保留开具时的价格保证一致性。

**索引**：`prescription_id` INDEX

```
Schema::create('prescription_items', function (Blueprint $table) {
    $table->id()->comment('主键ID');
    $table->unsignedBigInteger('prescription_id')->comment('处方ID');
    $table->unsignedBigInteger('drug_id')->comment('药品ID');
    $table->unsignedInteger('quantity')->comment('数量');
    $table->decimal('unit_price', 10, 2)->comment('开具时药品单价');
    $table->string('dosage', 255)->comment('用量说明');
    $table->text('instructions')->nullable()->comment('用药说明');
    $table->timestamps();

    $table->foreign('prescription_id')->references('id')->on('prescriptions')->onDelete('cascade');
    $table->foreign('drug_id')->references('id')->on('drugs');
    $table->index('prescription_id');
});
```

### 2.6 AI 诊断报告表 `ai_diagnoses`

统一存储文字诊断（患者端）和图文诊断（医生端），通过 `type` 区分。

| 字段名                      | 数据类型             | 必填 | 默认值            | 说明                                           |
| :-------------------------- | :------------------- | :--- | :---------------- | :--------------------------------------------- |
| `id`                        | BIGINT UNSIGNED      | ✅    | AUTO_INCREMENT    | 主键                                           |
| `type`                      | ENUM('text','image') | ✅    | —                 | text-文字诊断，image-图文诊断                  |
| `patient_id`                | BIGINT UNSIGNED      | ✅    | —                 | 患者 ID，FK → `users.id`                       |
| `doctor_id`                 | BIGINT UNSIGNED      | 否   | NULL              | 医生 ID（图文诊断时有值）                      |
| `appointment_id`            | BIGINT UNSIGNED      | 否   | NULL              | 关联预约 ID                                    |
| `symptom_description`       | TEXT                 | 否   | NULL              | 文字诊断：原始症状描述                         |
| `analysis`                  | TEXT                 | 否   | NULL              | 文字诊断：病情分析                             |
| `risk_level`                | VARCHAR(20)          | 否   | NULL              | 风险等级（低风险/中风险/高风险），两种诊断共用 |
| `risk_warning`              | TEXT                 | 否   | NULL              | 文字诊断：风险提示                             |
| `advice`                    | TEXT                 | 否   | NULL              | 文字诊断：就诊建议                             |
| `possible_conditions`       | JSON                 | 否   | NULL              | 文字诊断：可能情况列表                         |
| `description`               | TEXT                 | 否   | NULL              | 图文诊断：病情文字描述                         |
| `imaging_features`          | TEXT                 | 否   | NULL              | 图文诊断：影像特征分析                         |
| `suspected_lesions`         | TEXT                 | 否   | NULL              | 图文诊断：疑似病灶分析                         |
| `treatment_recommendations` | TEXT                 | 否   | NULL              | 图文诊断：专业诊疗建议                         |
| `confidence`                | DECIMAL(5,2)         | 否   | NULL              | 图文诊断：AI 置信度（如 0.92 表示 92%）        |
| `image_url`                 | VARCHAR(255)         | 否   | NULL              | 图文诊断：CT 影像图片地址                      |
| `created_at`                | TIMESTAMP            | ✅    | CURRENT_TIMESTAMP | 诊断时间                                       |
| `updated_at`                | TIMESTAMP            | ✅    | CURRENT_TIMESTAMP | 更新时间                                       |

**type 与字段对应关系**：

| type=text                                                    | type=image                                                   |
| :----------------------------------------------------------- | :----------------------------------------------------------- |
| symptom_description, analysis, risk_level, risk_warning, advice, possible_conditions | description, imaging_features, risk_level, suspected_lesions, treatment_recommendations, confidence, image_url |

> **V2.1 变更**：`risk_assessment` 与 `risk_level` 统一为 `risk_level`；`confidence` 从 VARCHAR(10) 改为 DECIMAL(5,2)。

**索引**：`type` INDEX, `patient_id` INDEX, `created_at` INDEX

```
Schema::create('ai_diagnoses', function (Blueprint $table) {
    $table->id()->comment('主键ID');
    $table->enum('type', ['text', 'image'])->comment('诊断类型');
    $table->unsignedBigInteger('patient_id')->comment('患者ID');
    $table->unsignedBigInteger('doctor_id')->nullable()->comment('医生ID（图文诊断时有值）');
    $table->unsignedBigInteger('appointment_id')->nullable()->comment('关联预约ID');
    // 文字诊断字段
    $table->text('symptom_description')->nullable()->comment('文字诊断：原始症状描述');
    $table->text('analysis')->nullable()->comment('文字诊断：病情分析');
    $table->string('risk_level', 20)->nullable()->comment('风险等级（低风险/中风险/高风险）');
    $table->text('risk_warning')->nullable()->comment('文字诊断：风险提示');
    $table->text('advice')->nullable()->comment('文字诊断：就诊建议');
    $table->json('possible_conditions')->nullable()->comment('文字诊断：可能情况列表');
    // 图文诊断字段
    $table->text('description')->nullable()->comment('图文诊断：病情描述');

### 2.7 药品表 `drugs`

医生管理药品库存，患者取药时系统自动扣减。

| 字段名                | 数据类型                      | 必填 | 默认值            | 说明                                     |
| :-------------------- | :---------------------------- | :--- | :---------------- | :--------------------------------------- |
| `id`                  | BIGINT UNSIGNED               | ✅    | AUTO_INCREMENT    | 主键                                     |
| `name`                | VARCHAR(255)                  | ✅    | —                 | 药品名称，唯一                           |
| `category`            | VARCHAR(100)                  | ✅    | —                 | 药品分类（靶向药物/化疗药物/辅助用药等） |
| `specification`       | VARCHAR(100)                  | ✅    | —                 | 规格（如"250mg×10片"）                   |
| `unit`                | VARCHAR(20)                   | ✅    | —                 | 单位（盒/瓶/支）                         |
| `stock_quantity`      | INT UNSIGNED                  | ✅    | 0                 | 当前库存数量                             |
| `low_stock_threshold` | INT UNSIGNED                  | ✅    | 10                | 库存预警阈值                             |
| `price`               | DECIMAL(10,2)                 | ✅    | —                 | 单价（元），>0                           |
| `status`              | ENUM('active','discontinued') | ✅    | 'active'          | active-正常，discontinued-已停售         |
| `description`         | TEXT                          | 否   | NULL              | 药品说明                                 |
| `created_at`          | TIMESTAMP                     | ✅    | CURRENT_TIMESTAMP | 创建时间                                 |
| `updated_at`          | TIMESTAMP                     | ✅    | CURRENT_TIMESTAMP | 更新时间                                 |

**业务规则**：

- `is_low_stock` = `stock_quantity <= low_stock_threshold`（应用层计算，无需存储）
- `status=discontinued` 的药品不可被新处方引用，但不影响历史数据查询
- 初始入库不生成库存变动记录
- 编辑药品不含 `stock_quantity`，库存变更须通过入库接口

**索引**：`name` UNIQUE, `category` INDEX

```
Schema::create('drugs', function (Blueprint $table) {

});

### 2.8 库存变动记录表 `stock_movements`

每次库存变动均生成一条不可变记录，支持全链路追溯。`type=out` 仅由系统自动生成，禁止手动出库。

| 字段名            | 数据类型         | 必填 | 默认值            | 说明                                                      |
| :---------------- | :--------------- | :--- | :---------------- | :-------------------------------------------------------- |
| `id`              | BIGINT UNSIGNED  | ✅    | AUTO_INCREMENT    | 主键                                                      |
| `drug_id`         | BIGINT UNSIGNED  | ✅    | —                 | 药品 ID，FK → `drugs.id`                                  |
| `type`            | ENUM('in','out') | ✅    | —                 | in-入库，out-出库（系统自动）                             |
| `quantity`        | INT UNSIGNED     | ✅    | —                 | 变动数量                                                  |
| `before_quantity` | INT UNSIGNED     | ✅    | —                 | 变动前库存                                                |
| `after_quantity`  | INT UNSIGNED     | ✅    | —                 | 变动后库存                                                |
| `reference_type`  | VARCHAR(50)      | ✅    | —                 | 关联业务类型：`manual_stock_in` / `prescription_dispense` |
| `reference_id`    | BIGINT UNSIGNED  | 否   | NULL              | 关联业务 ID                                               |
| `remark`          | TEXT             | 否   | NULL              | 备注                                                      |
| `operator_id`     | BIGINT UNSIGNED  | 否   | NULL              | 操作人 ID，出库时 NULL 表示系统自动                       |
| `created_at`      | TIMESTAMP        | ✅    | CURRENT_TIMESTAMP | 变动时间（不可变，无 updated_at）                         |

**业务规则**：

- 入库：`type=in`，`reference_type=manual_stock_in`，`operator_id` 为操作用户
- 出库：`type=out`，`reference_type=prescription_dispense`，`reference_id` 为处方 ID，`operator_id=NULL`
- `after_quantity = before_quantity ± quantity`

**索引**：`drug_id` INDEX, `type` INDEX, `created_at` INDEX, `(reference_type, reference_id)` INDEX

```
Schema::create('stock_movements', function (Blueprint $table) {
    $table->id()->comment('主键ID');
    $table->unsignedBigInteger('drug_id')->comment('药品ID');
    $table->enum('type', ['in', 'out'])->comment('变动类型');
    $table->unsignedInteger('quantity')->comment('变动数量');
    $table->unsignedInteger('before_quantity')->comment('变动前库存');
    $table->unsignedInteger('after_quantity')->comment('变动后库存');
    $table->string('reference_type', 50)->comment('关联业务类型');
    $table->unsignedBigInteger('reference_id')->nullable()->comment('关联业务ID');
    $table->text('remark')->nullable()->comment('备注');
    $table->unsignedBigInteger('operator_id')->nullable()->comment('操作人ID');
    $table->timestamp('created_at')->useCurrent()->comment('变动时间');

    $table->foreign('drug_id')->references('id')->on('drugs');
    $table->foreign('operator_id')->references('id')->on('users');
    $table->index('drug_id');
    $table->index('type');
    $table->index('created_at');
    $table->index(['reference_type', 'reference_id']);
});
```

## 三、关键业务约束总结

| 约束                      | 实现方式                                | 所在表                                        |
| :------------------------ | :-------------------------------------- | :-------------------------------------------- |
| 邮箱唯一                  | UNIQUE INDEX                            | `users.email`                                 |
| 同一预约仅 1 份病历       | UNIQUE INDEX                            | `medical_records.appointment_id`              |
| 患者同时仅 1 个进行中预约 | 应用层校验 + 悲观锁                     | `appointments`                                |
| 开具处方不扣库存          | 应用层：仅 SELECT 校验                  | `prescriptions` + `prescription_items`        |
| 取药时原子扣减            | DB 事务 + `stock_movements` 日志        | `prescriptions` + `drugs` + `stock_movements` |
| 药品名称唯一              | UNIQUE INDEX                            | `drugs.name`                                  |
| 库存不足预警              | `stock_quantity <= low_stock_threshold` | `drugs`                                       |
| 历史处方金额不变          | `unit_price` 快照                       | `prescription_items.unit_price`               |
