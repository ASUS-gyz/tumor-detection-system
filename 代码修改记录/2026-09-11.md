## 变更 4：修复 BulkDataSeeder 双重 JSON 编码（验证 #3 时发现的数据质量缺陷）

- **修改人**：ASUS-gyz（git config user.name）
- **修改时间**：2026-09-11 15:04:17

### 删除范围

1. `database/seeders/BulkDataSeeder.php` `seedDoctorSchedules()`：删除 `'time_slots' => json_encode($this->timeSlots)` 的预编码写法（模型 array cast 会再编码一次，导致入库值双重编码，cast 后得到字符串而非数组，排班时段校验失效）。
2. `database/seeders/BulkDataSeeder.php` `seedAiDiagnoses()`：删除 `'possible_conditions' => json_encode([...])` 的预编码写法（同因）。

### 新增范围

1. `database/seeders/BulkDataSeeder.php`：`'time_slots' => $this->timeSlots`、`'possible_conditions' => [...]`，均传 PHP 数组交由模型 array cast 统一编码，并加注释说明勿预 json_encode。

### 说明

- 验证变更 3 的排班校验时发现：bulk 系医生（doctor 5-10）共 42/49 行 `doctor_schedules.time_slots`、15/18 行 `ai_diagnoses.possible_conditions` 为双重编码（如 `"[\"08:30\",...]"`），模型 cast 后是字符串不是数组，时段校验对这些医生不生效。数据修复已记录至数据库变更记录。修复后 bulk 医生预约路径实测：排班正常生效、非法时段 10001 拒绝。
- GYZTestDataSeeder 写法正确（传数组），doctor_li（doctor 2）数据未受影响。
