# 前端接口文档

> **Base URL**：`http://127.0.0.1:8000/api` | **接口总数**：43 | **最后更新**：2026-07-29

---

## 通用约定

### 请求认证

登录/注册后拿到的 `token`，在所有需认证接口的 Header 中传入：

```
Authorization: Bearer <token>
```

### 响应格式

```json
// 成功
{ "code": 0, "msg": "成功", "data": {...}, "success": true, "trace_id": "uuid" }
// 失败
{ "code": 20001, "msg": "未登录", "data": null, "success": false, "trace_id": "uuid" }
```

### 分页格式

```json
{ "list": [...], "page": 1, "size": 10, "total": 100, "total_pages": 10 }
```

### 角色枚举

| 值 | 身份 |
|----|------|
| `patient` | 患者 |
| `doctor` | 医生 |
| `admin` | 管理员 |

### 常见错误码

| code | 含义 | 触发场景 |
|------|------|----------|
| 0 | 成功 | — |
| 10001 | 参数错误 | 字段缺失/格式不符/验证失败 |
| 20001 | 未登录 | 无 token |
| 20005 | 无权限 | 角色不匹配 |
| 20006 | 账号禁用 | status=disabled |
| 20008 | 密码错误 | 登录/注销/改密 |
| 30001 | 不存在 | 资源未找到 |
| 40002 | 状态不可操作 | 取消非 pending 预约等 |
| 40004 | 库存不足 | 取药/开药时 |
| 40009 | 重复操作 | 已有进行中预约/病历 |
| 50001 | AI 服务异常 | AI 接口调用失败 |

### 密码规则

≥8 位，必须包含 **大写字母 + 小写字母 + 数字 + 特殊符号** 中至少 **3** 种。

### 预约时段

固定 8 个：`08:30 / 09:15 / 10:00 / 10:45 / 13:30 / 14:15 / 15:00 / 15:45`

## 一、认证模块（10 个）

### 1.1 注册

```
POST /auth/register
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | ✅ | 2-50 字符 |
| email | string | ✅ | 唯一 |
| password | string | ✅ | ≥8位，3/4 复杂度 |
| phone | string | 否 | 11 位 |

**返回**：

```json
{ "data": { "user": { "id":1, "name":"张三", "email":"...", "role":"patient", "phone":null, "avatar_url":null, "status":"active", "created_at":"..." }, "token": "明文token", "token_type": "Bearer" } }
```

> 角色固定 `patient`，同时返回 token 可直接登录。

---

### 1.2 登录

```
POST /auth/login
```

| 参数 | 类型 | 必填 |
|------|------|------|
| email | string | ✅ |
| password | string | ✅ |

**返回**：同注册（user + token）。

**异常**：20008（密码错误）、20006（账号禁用）。

---

### 1.3 退出

```
POST /auth/logout
```

无参数。返回 `msg: "退出成功"`。

---

### 1.4 当前用户

```
GET /auth/me
```

**返回**：`{ id, name, email, role, phone, avatar_url, status, created_at }`（医生加 title/specialty/department/introduction/experience_years）。

---

### 1.5 修改密码

```
PUT /auth/password
```

| 参数 | 类型 | 必填 |
|------|------|------|
| current_password | string | ✅ |
| new_password | string | ✅（3/4 复杂度） |
| new_password_confirmation | string | ✅ |

---

### 1.6 上传头像

```
POST /auth/avatar
Content-Type: multipart/form-data
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| avatar | file | ✅ | jpg/jpeg/png/webp，≤2MB |

**返回**：`{ "avatar_url": "http://127.0.0.1:8000/storage/avatars/xxx.png" }`

---

### 1.7 更新资料

```
PUT /auth/profile
```

| 参数 | 类型 | 说明 |
|------|------|------|
| name | string | 所有角色 |
| phone | string | 所有角色 |
| title | string | 医生：职称 |
| specialty | string | 医生：专长 |
| department | string | 医生：科室 |
| introduction | string | 医生：简介 |
| experience_years | int | 医生：从业年限 |

> 患者只能改 name/phone。传什么改什么。

---

### 1.8 忘记密码

```
POST /auth/forgot-password
```

| 参数 | 类型 | 必填 |
|------|------|------|
| email | string | ✅ |

**返回**：`msg: "验证码已发送至您的邮箱，请查收"`。

> 6 位数字验证码发到邮箱，60 分钟有效。API 响应不包含验证码。

---

### 1.9 重置密码

```
POST /auth/reset-password
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | ✅ | |
| token | string | ✅ | 邮箱收到的 6 位验证码 |
| password | string | ✅ | 新密码（3/4 复杂度） |
| password_confirmation | string | ✅ | |

> 60 分钟过期，用完即删。

---

### 1.10 注销账号

```
DELETE /auth/account
```

| 参数 | 类型 | 必填 |
|------|------|------|
| password | string | ✅ |

> 注销后 status=disabled，token 全部失效。

---

### 2.2 医生列表

```
GET /patient/doctors?keyword=肿瘤&page=1&per_page=10
```

**返回**（分页）：

```json
{ "list": [{ "id":2, "name":"王医生", "title":"主任医师", "specialty":"肺部肿瘤", "department":"肿瘤内科", "introduction":"...", "experience_years":20, "avatar_url":null }] }
```

---

### 2.3 医生详情

```
GET /patient/doctors/{id}
```

**返回**：同列表 + `phone`。

---

### 2.4 创建预约

```
POST /patient/appointments
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| doctor_id | int | ✅ | |
| appointment_date | string | ✅ | `2026-08-01`，≥今天 |
| appointment_time | string | ✅ | 8 个时段之一 |

**返回**：

```json
{ "data": { "id":1, "appointment_date":"...", "appointment_time":"09:15", "status":"pending", "doctor": {"id":2,"name":"王医生","title":"主任医师","department":"肿瘤内科"}, "created_at":"..." } }
```

> 已有进行中预约 → 40009。

---

### 2.5 可预约时段

```
GET /patient/appointments/available-slots?doctor_id=2&date=2026-08-01
```

**返回**：

```json
{ "data": { "date":"2026-08-01", "all_slots":["08:30"...], "booked_slots":["09:15"], "available_slots":["08:30","10:00"...] } }
```

> 前端用 `available_slots` 渲染可点时段。

---

### 2.6 预约列表

```
GET /patient/appointments?status=pending&date=2026-08-01&page=1
```

**返回**（分页）：同 2.4 列表项结构。

---

### 2.7 预约详情（聚合）

```
GET /patient/appointments/{id}
```

```json
{ "data": { "id":1, "appointment_date":"...", "appointment_time":"09:15", "status":"completed",
    "doctor": {"id":2,"name":"王医生","title":"主任医师","specialty":"肺部肿瘤","department":"肿瘤内科"},
    "medical_record": {"id":1,"symptoms":"...","imaging_findings":"...","preliminary_diagnosis":"...","treatment_plan":"...","created_at":"..."},
    "prescription": {"id":1,"status":"dispensed","items":[{"id":1,"drug_id":1,"quantity":3,"dosage":"每日1次","instructions":"空腹"}],"created_at":"..."},
    "ai_diagnosis": {"id":1,"type":"text","symptom_description":"...","analysis":"...","risk_level":"高风险","risk_warning":"...","advice":"...","possible_conditions":["肺癌","肺结核"],"created_at":"..."},
    "created_at":"..." } }
```

> 一条接口拿齐所有关联数据。未创建部分为 `null`。

---

### 2.8 取消预约

```
DELETE /patient/appointments/{id}
```

> 仅 `pending` 可取消。

---

### 2.9 就诊评价

```
POST /patient/appointments/{id}/review
```

|------|------|------|------|
| rating | int | ✅ | 1-5 星 |

> 仅 `completed` 可评价。

## 三、患者端 — AI 诊断（5 个）

### 3.1 创建诊断

```
POST /patient/ai-diagnosis
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| symptom_description | string | ✅ | 2-2000 字 |
| appointment_id | int | 否 | |

**返回**：

```json
{ "data": { "id":1, "type":"text", "symptom_description":"...", "analysis":"...", "risk_level":"高风险", "risk_warning":"...", "advice":"...", "possible_conditions":["肺癌","肺结核"], "created_at":"..." } }
```

> 调用 DeepSeek API，约 2-5 秒。`AI_MODE=mock` 走本地模拟数据。

---

### 3.2 诊断列表

```
GET /patient/ai-diagnosis?page=1
```

**返回**（分页）：`{ id, type, symptom_description(截50字), risk_level, created_at }`

---

### 3.3 诊断详情

```
GET /patient/ai-diagnosis/{id}
```

返回同 3.1。

---

### 3.4 AI 追问

```
POST /patient/ai-diagnosis/continue
```

| 参数 | 类型 | 必填 |
|------|------|------|
| diagnosis_id | int | ✅ |
| question | string | ✅ |

**返回**：`{ previous_id, diagnosis: 完整新诊断 }`

---

### 3.5 导出报告

```
GET /patient/ai-diagnosis/{id}/export
```

**返回**：`{ report: { title, report_no, patient_name, risk_level, analysis, advice, disclaimer } }`

> 前端拿此数据渲染 PDF。

```

```

### 4.4 处方详情

```json

    "created_at":"..." } }
```

---

### 4.5 确认取药

```
POST /patient/prescriptions/{id}/confirm
```

> 仅 `pending` 可操作。后端事务：锁行→扣库存→记日志→改状态。
> 库存不足 → 40004（含具体药品名）。

---

### 4.6 续方申请

```
POST /patient/prescriptions/{id}/refill
```

> 仅 `dispensed` 可续方。返回原处方药品清单。

---

### 4.7 用药提醒

```
GET /patient/medication-reminders
```

> 返回 `pending` 处方的药品名、用法、医生。
