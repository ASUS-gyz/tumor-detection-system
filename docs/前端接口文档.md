# 前端接口文档（ZZT 模块）

> **Base URL**：`http://127.0.0.1:8000/api`（开发环境）
> **接口总数**：43
> **最后更新**：2026-07-29

---

## 通用约定

### 认证

需要登录的接口在 Header 加：

```
Authorization: Bearer <token>
```

token 通过注册或登录接口获取。

### 响应格式

```json
// 成功
{ "code": 0, "msg": "成功", "data": {...}, "success": true, "trace_id": "uuid" }

// 失败
{ "code": 20001, "msg": "未登录", "data": null, "success": false, "trace_id": "uuid" }
```

### 分页格式

```json
{ "list": [...], "page": 1, "size": 10, "total": 100, "total_pages": 10 }
```

### 角色枚举

| 值 | 身份 |
|----|------|
| `patient` | 患者 |
| `doctor` | 医生 |
| `admin` | 管理员 |

### 常见错误码

| code | 含义 |
|------|------|
| 0 | 成功 |
| 10001 | 参数错误 |
| 20001 | 未登录 |
| 20005 | 无权限（角色不对） |
| 20006 | 账号已禁用 |
| 20008 | 密码错误 |
| 30001 | 记录不存在 |
| 40002 | 状态不允许操作 |
| 40004 | 库存不足 |
| 40009 | 重复操作 |

## 一、认证模块（10 个）

### 1.1 患者注册

```
POST /auth/register
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | ✅ | 2-50 字符 |
| email | string | ✅ | 邮箱，不可重复 |
| password | string | ✅ | ≥8位，必须含大写+小写+数字+特殊符号中≥3种 |
| phone | string | 否 | 11 位手机号 |

**返回**：

```json
{
  "data": {
    "user": { "id": 1, "name": "张三", "email": "zhangsan@qq.com", "role": "patient", "phone": null, "avatar_url": null, "status": "active", "created_at": "2026-07-29T10:00:00" },
    "token": "明文token字符串",
    "token_type": "Bearer"
  }
}
```

> 注册后角色固定为 `patient`，同时返回 token 可直接登录。

---

### 1.2 登录

```
POST /auth/login
```

| 参数 | 类型 | 必填 |
|------|------|------|
| email | string | ✅ |
| password | string | ✅ |

**返回**：同注册，`user` + `token`。

> 登录失败：20006（账号禁用）、20008（密码错误）。

---

### 1.3 退出登录

```
POST /auth/logout
```

无参数。返回 `msg: "退出成功"`。

---

### 1.4 当前用户信息

```
GET /auth/me
```

**返回**：

```json
{
  "data": {
    "id": 1, "name": "张三", "email": "zhangsan@qq.com", "role": "patient",
    "phone": "13800138000", "avatar_url": "http://...", "status": "active",
    "created_at": "2026-07-29T10:00:00"
  }
}
```

> 医生额外返回：`title`, `specialty`, `department`, `introduction`, `experience_years`。

---

### 1.5 修改密码

```
PUT /auth/password
```

| 参数 | 类型 | 必填 |
|------|------|------|
| current_password | string | ✅ |
| new_password | string | ✅（规则同注册） |
| new_password_confirmation | string | ✅（须与 new_password 一致） |

---

### 1.6 上传头像

```
POST /auth/avatar
Content-Type: multipart/form-data
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| avatar | file | ✅ | jpg/jpeg/png/webp，≤2MB |

**返回**：`{ "avatar_url": "http://127.0.0.1:8000/storage/avatars/xxx.png" }`

---

### 1.7 更新个人资料

```
PUT /auth/profile
```

| 参数 | 类型 | 说明 |
|------|------|------|
| name | string | 姓名 |
| phone | string | 11 位手机号 |
| title | string | 职称（仅 doctor） |
| specialty | string | 专长（仅 doctor） |
| department | string | 科室（仅 doctor） |
| introduction | string | 简介（仅 doctor） |
| experience_years | int | 从业年限（仅 doctor） |

> 患者只能改 name/phone，医生可额外改专业信息。传什么改什么。

---

### 1.8 忘记密码

```
POST /auth/forgot-password
```

| 参数 | 类型 | 必填 |
|------|------|------|
| email | string | ✅ |

**返回**：`msg: "验证码已发送至您的邮箱，请查收"`。

> 系统发送 6 位数字验证码到邮箱，60 分钟内有效。API 响应不包含验证码。

---

### 1.9 重置密码

```
POST /auth/reset-password
```

| 参数 | 类型 | 必填 |
|------|------|------|
| email | string | ✅ |
| token | string | ✅（邮箱收到的 6 位验证码） |
| password | string | ✅（新密码，规则同注册） |
| password_confirmation | string | ✅ |

> 验证码 60 分钟过期，使用一次即删除。

---

### 1.10 注销账号

```
DELETE /auth/account
```

| 参数 | 类型 | 必填 |
|------|------|------|
| password | string | ✅（确认身份） |

> 注销后账号 `status` 变为 `disabled`，所有 token 失效。
