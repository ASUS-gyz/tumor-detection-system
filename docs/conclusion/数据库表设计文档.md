# 用户表 (users)

所有角色（患者、医生、管理员）共用此表，通过 `role` 字段区分。患者通过注册接口创建，医生/管理员由后台创建。

| 字段名 | 数据类型 | 必填 | 说明 |
|--------|----------|------|------|
| `id` | BIGINT (Unsigned) | ✅ 是 | 主键，自增，用户唯一标识。 |
| `name` | VARCHAR(50) | ✅ 是 | 姓名，2-50 字符，支持中文。 |
| `email` | VARCHAR(255) | ✅ 是 | 邮箱地址，需唯一。 |
| `password` | VARCHAR(255) | ✅ 是 | 密码，bcrypt 加密存储。 |
| `role` | ENUM('patient','doctor','admin') | ✅ 是 | 角色：patient-患者，doctor-医生，admin-管理员。 |
| `phone` | VARCHAR(20) | 否 | 手机号码，11 位。 |
| `avatar_url` | VARCHAR(255) | 否 | 头像访问地址。 |
| `status` | ENUM('active','disabled') | ✅ 是 | 账号状态：active-正常，disabled-已禁用。 |
| `title` | VARCHAR(50) | 否 | 职称（主任医师 / 副主任医师 / 主治医师），仅 doctor 有值。 |
| `specialty` | VARCHAR(255) | 否 | 专长，仅 doctor 有值。 |
| `department` | VARCHAR(100) | 否 | 科室，仅 doctor 有值。 |
| `introduction` | TEXT | 否 | 个人简介，仅 doctor 有值。 |
| `experience_years` | INT (Unsigned) | 否 | 从业年限，仅 doctor 有值。 |
| `created_at` | TIMESTAMP | ✅ 是 | 创建时间。 |
| `updated_at` | TIMESTAMP | ✅ 是 | 更新时间。 |

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('users', function (Blueprint $table) {
            $table->id()->comment('主键ID');
            $table->string('name', 50)->comment('姓名');
            $table->string('email', 255)->unique()->comment('邮箱');
            $table->string('password', 255)->comment('密码');
            $table->enum('role', ['patient', 'doctor', 'admin'])->comment('角色');
            $table->string('phone', 20)->nullable()->comment('手机号');
            $table->string('avatar_url', 255)->nullable()->comment('头像地址');
            $table->enum('status', ['active', 'disabled'])->default('active')->comment('账号状态');
            $table->string('title', 50)->nullable()->comment('职称');
            $table->string('specialty', 255)->nullable()->comment('专长');
            $table->string('department', 100)->nullable()->comment('科室');
            $table->text('introduction')->nullable()->comment('个人简介');
            $table->unsignedInteger('experience_years')->nullable()->comment('从业年限');
            $table->timestamps();

            $table->index('role');
            $table->index('status');
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('users');
    }
```

# 预约表 (appointments)

患者创建预约，医生管理接诊。对应患者端"预约管理"和医生端"接诊管理"模块。

| 字段名 | 数据类型 | 必填 | 说明 |
|--------|----------|------|------|
| `id` | BIGINT (Unsigned) | ✅ 是 | 主键，自增，预约唯一标识。 |
| `patient_id` | BIGINT (Unsigned) | ✅ 是 | 患者 ID，外键关联 `users.id`。 |
| `doctor_id` | BIGINT (Unsigned) | ✅ 是 | 医生 ID，外键关联 `users.id`。 |
| `appointment_date` | DATE | ✅ 是 | 预约日期，不能早于当天。 |
| `appointment_time` | VARCHAR(5) | ✅ 是 | 预约时段 HH:mm，可选值：08:30 / 09:15 / 10:00 / 10:45 / 13:30 / 14:15 / 15:00 / 15:45。 |
| `status` | ENUM('pending','called','in_progress','completed','cancelled') | ✅ 是 | 预约状态：pending-待接诊，called-已叫号，in_progress-接诊中，completed-已完成，cancelled-已取消。 |
| `created_at` | TIMESTAMP | ✅ 是 | 创建时间。 |
| `updated_at` | TIMESTAMP | ✅ 是 | 更新时间。 |

状态流转：`pending → called → in_progress → completed`，`pending → cancelled`。

**业务约束**：患者同时只能有 1 个进行中预约；仅 `pending` 可取消。

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('appointments', function (Blueprint $table) {
            $table->id()->comment('主键ID');
            $table->unsignedBigInteger('patient_id')->comment('患者ID');
            $table->unsignedBigInteger('doctor_id')->comment('医生ID');
            $table->date('appointment_date')->comment('预约日期');
            $table->string('appointment_time', 5)->comment('预约时段 HH:mm');
            $table->enum('status', ['pending', 'called', 'in_progress', 'completed', 'cancelled'])
                  ->default('pending')->comment('预约状态');
            $table->timestamps();

            $table->foreign('patient_id')->references('id')->on('users');
            $table->foreign('doctor_id')->references('id')->on('users');
            $table->index('appointment_date');
            $table->index('status');
            $table->index(['patient_id', 'status']);
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('appointments');
    }
};
```

|--------|----------|------|------|
| `id` | BIGINT (Unsigned) | ✅ 是 | 主键，自增，处方唯一标识。 |

| `status` | ENUM('pending','dispensed') | ✅ 是 | 处方状态：pending-待取药，dispensed-已取药。 |
| `created_at` | TIMESTAMP | ✅ 是 | 开具时间。 |
| `updated_at` | TIMESTAMP | ✅ 是 | 更新时间。 |

# AI 诊断报告表 (ai_diagnoses)

统一存储文字诊断（患者端）和图文诊断（医生端）两种报告，通过 `type` 字段区分。

| 字段名 | 数据类型 | 必填 | 说明 |
|--------|----------|------|------|
| `id` | BIGINT (Unsigned) | ✅ 是 | 主键，自增，诊断报告唯一标识。 |
| `type` | ENUM('text','image') | ✅ 是 | 诊断类型：text-文字诊断（患者端），image-图文诊断（医生端）。 |
| `patient_id` | BIGINT (Unsigned) | ✅ 是 | 患者 ID，外键关联 `users.id`。 |
| `doctor_id` | BIGINT (Unsigned) | 否 | 医生 ID，外键关联 `users.id`。文字诊断时为 NULL。 |
| `appointment_id` | BIGINT (Unsigned) | 否 | 关联预约 ID，外键关联 `appointments.id`。 |
| `symptom_description` | TEXT | 否 | **文字诊断**：原始症状描述。 |
| `description` | TEXT | 否 | **图文诊断**：病情文字描述。 |
| `analysis` | TEXT | 否 | **文字诊断**：病情分析。 |
| `risk_level` | VARCHAR(20) | 否 | **文字诊断**：风险等级（低风险 / 中风险 / 高风险）。 |
| `risk_warning` | TEXT | 否 | **文字诊断**：风险提示。 |
| `advice` | TEXT | 否 | **文字诊断**：就诊建议。 |
| `possible_conditions` | JSON | 否 | **文字诊断**：可能情况列表，如 `["肺部良性病变","肺部恶性肿瘤可能"]`。 |
| `imaging_features` | TEXT | 否 | **图文诊断**：影像特征分析。 |
| `risk_assessment` | VARCHAR(20) | 否 | **图文诊断**：风险评估（低风险 / 中风险 / 高风险）。 |
| `suspected_lesions` | TEXT | 否 | **图文诊断**：疑似病灶分析。 |
| `treatment_recommendations` | TEXT | 否 | **图文诊断**：专业诊疗建议。 |
| `confidence` | VARCHAR(10) | 否 | **图文诊断**：AI 置信度，如 "92%"。 |
| `image_url` | VARCHAR(255) | 否 | **图文诊断**：CT 影像图片访问地址。 |
| `created_at` | TIMESTAMP | ✅ 是 | 诊断时间。 |
| `updated_at` | TIMESTAMP | ✅ 是 | 更新时间。 |

**type 与字段对应关系**：

| type=text | type=image |
|-----------|------------|
| symptom_description, analysis, risk_level, risk_warning, advice, possible_conditions | description, imaging_features, risk_assessment, suspected_lesions, treatment_recommendations, confidence, image_url |

**业务说明**：当前开发阶段使用 Mock 模式；患者仅可查看本人报告；医生可查看所有患者报告。

| 字段名 | 数据类型 | 必填 | 说明 |
|--------|----------|------|------|
| `id` | BIGINT (Unsigned) | ✅ 是 | 主键，自增，变动记录唯一标识。 |
| `drug_id` | BIGINT (Unsigned) | ✅ 是 | 药品 ID，外键关联 `drugs.id`。 |
| `type` | ENUM('in','out') | ✅ 是 | 变动类型：in-入库，out-出库（系统自动扣减）。 |
| `quantity` | INT (Unsigned) | ✅ 是 | 变动数量。 |
| `before_quantity` | INT (Unsigned) | ✅ 是 | 变动前库存。 |
| `after_quantity` | INT (Unsigned) | ✅ 是 | 变动后库存（before ± quantity）。 |
| `reference_type` | VARCHAR(50) | ✅ 是 | 关联业务类型：manual_stock_in-手动入库，prescription_dispense-处方取药自动扣减。 |
| `reference_id` | BIGINT (Unsigned) | 否 | 关联业务 ID（入库记录 ID 或处方 ID）。 |
| `remark` | TEXT | 否 | 备注。 |
| `operator_id` | BIGINT (Unsigned) | 否 | 操作人 ID，外键关联 `users.id`。出库时可为 NULL 表示系统自动。 |
| `created_at` | TIMESTAMP | ✅ 是 | 变动时间。 |

```php
<?php

use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{

            $table->id()->comment('主键ID');

            $table->unsignedInteger('quantity')->comment('变动数量');
```
