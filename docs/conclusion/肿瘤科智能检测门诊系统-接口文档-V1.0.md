# 肿瘤科智能检测门诊系统 — 接口文档 V1.0

> 基于《肿瘤科智能检测门诊系统-业务功能文档(学生开发版)》输出。
>
> 目标：给前端、后端、测试提供一份统一的 **最新接口契约**。
>
> 本文档按功能模块划分，覆盖全部核心接口：**认证、患者预约、患者AI诊断、患者病历处方、医生接诊、医生病历处方、医生AI图文诊断、医生药品库存、管理员用户管理、管理员数据监控**。

---

## 1. 通用约定

### 1.1 Base URL
- **本地开发**：`http://127.0.0.1:8000`

### 1.2 鉴权方式
采用 **Laravel Sanctum / Session** 鉴权。
- 公开接口：`/api/auth/register`、`/api/auth/login`
- 患者端 `/api/patient/*` — 需登录，角色 `patient`
- 医生端 `/api/doctor/*` — 需登录，角色 `doctor`
- 管理员端 `/api/admin/*` — 需登录，角色 `admin`

### 1.3 统一响应格式

```json
{ "code": 0, "msg": "成功", "data": {}, "success": true, "trace_id": "8f45a7d5-d8b2-4d7a-b6e3-123456789abc" }
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | number | 业务状态码，成功为 `0` |
| msg | string | 业务提示信息 |
| data | mixed | 返回数据 |
| success | boolean | 是否成功 |
| trace_id | string | 链路追踪 ID |

### 1.4 分页响应格式
```json
{ "list": [], "page": 1, "size": 10, "total": 100, "total_pages": 10 }
```

### 1.5 时间与排序约定
- 时间字段：ISO 8601，如 `2026-07-26T14:30:00`
- 分页：`page` 从 `1` 开始，`size` 默认 `10`

### 1.6 请求参数示例写法
统一采用 `path` / `query` / `body` / `formData` 结构，无对应参数写 `null` 或 `{}`。

### 1.7 通用枚举

| 枚举 | 值 | 说明 |
| --- | --- | --- |
| 用户角色 | `patient` / `doctor` / `admin` | 患者/医生/管理员 |
| 预约状态 | `pending` → `called` → `in_progress` → `completed` / `cancelled` | 待接诊→已叫号→接诊中→已完成/已取消 |
| 处方状态 | `pending` / `dispensed` | 待取药/已取药 |
| AI诊断类型 | `text` / `image` | 文字诊断/图文诊断 |
| 库存变动 | `in` / `out` | 入库/出库 |
| 账号状态 | `active` / `disabled` | 正常/禁用 |

## 2. 认证模块 ✅

> `/api/auth` | 公开/已登录 | 5 个接口

### 接口列表

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | 公开 | 患者注册 |
| POST | `/api/auth/login` | 公开 | 用户登录 |
| POST | `/api/auth/logout` | 已登录 | 退出登录 |
| GET | `/api/auth/me` | 已登录 | 获取当前用户信息 |
| PUT | `/api/auth/password` | 已登录 | 修改密码 |

### `POST /api/auth/register` — 患者注册

- **请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 姓名，2-50字符 |
| email | string | 是 | 邮箱地址 |
| password | string | 是 | 密码，6-100字符 |
| password_confirmation | string | 是 | 确认密码 |
| phone | string | 否 | 手机号码 |

```json
{ "body": { "name": "张三", "email": "zhangsan@example.com", "password": "password123", "password_confirmation": "password123", "phone": "13800138000" } }
```

- **响应 `data`**：`id / name / email / role:patient / created_at`
- **错误码**：`10001` 参数错误 / `30003` 邮箱已注册
- **业务规则**：仅患者可自助注册，医生/管理员由后台创建

### `POST /api/auth/login` — 用户登录

- **请求体**：`email`（是）、`password`（是）、`remember`（否）
- **响应 `data`**：`id / name / email / role / phone`
- **错误码**：`20008` 密码错误 / `20006` 账号被禁用

### `POST /api/auth/logout` — 退出登录

```json
{ "path": {}, "query": {}, "body": null }
```
- **响应 `data`**：`null`

### `GET /api/auth/me` — 获取当前用户信息

- **响应 `data`**：`id / name / email / role / phone / status / created_at`

### `PUT /api/auth/password` — 修改密码

- **请求体**：`current_password`（是）、`new_password`（是）、`new_password_confirmation`（是）
- **响应 `data`**：`null`

### `GET /api/doctor/drugs` — 药品库存列表

- **查询参数**：`page`、`size`、`keyword`、`category`、`low_stock`
- **响应 `data`**：分页 `id / name / category / specification / unit / stock_quantity / price / description / is_low_stock / created_at / updated_at`

### `POST /api/doctor/drugs` — 新增药品

- **请求体**：`DrugRequest`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 药品名称 |
| category | string | 是 | 药品分类 |
| specification | string | 是 | 规格 |
| unit | string | 是 | 单位 |
| stock_quantity | number | 是 | 初始库存 |
| price | number | 是 | 单价 |
| description | string | 否 | 药品说明 |

- **业务规则**：初始入库不生成变动记录

### `PUT /api/doctor/drugs/{id}` — 编辑药品

- **Path 参数**：`id` — 药品 ID
- **请求体**：同新增，所有字段可选（不含 `stock_quantity`，库存变更须走入库）

### `POST /api/doctor/drugs/{id}/stock-in` — 药品入库

- **Path 参数**：`id` — 药品 ID
- **请求体**：`quantity`（是，>0）、`remark`（否）
- **响应 `data`**：`drug_id / drug_name / before_quantity / after_quantity / stock_movement_id`
- **业务规则**：入库自动生成 `type=in` 变动记录；出库仅系统自动触发

### `GET /api/doctor/stock-movements` — 库存变动日志

- **查询参数**：`page`、`size`、`drug_id`、`type`（`in/out`）、`date_from`、`date_to`
- **响应 `data`**：分页 `id / drug_id / drug_name / type / quantity / before_quantity / after_quantity / reference_type / reference_id / remark / operator_name / created_at`

### 库存业务规则

| 规则 | 说明 |
| --- | --- |
| 自动扣减 | 患者确认取药 → 系统自动扣减 |
| 库存校验 | 开处方时校验 + 取药时二次校验 |
| 异常提示 | 库存不足自动阻止操作 |
| 全程追溯 | 每次变动记录前后数量和关联业务 |
| 禁止手动出库 | 出库仅系统触发 |

### `PUT /api/admin/users/{id}/status` — 启用/禁用

- **Path 参数**：`id` — 用户 ID
- **请求体**：`status`（是，`active/disab`）
- **业务规则**：不允许禁用自己
